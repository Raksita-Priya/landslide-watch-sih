# NEXORAZ

### AI & GIS Based Disaster Risk Management System for the North Eastern Region (NER), India

Built for Smart India Hackathon (SIH) 2026.

## Overview

NEXORAZ is a web-based disaster risk management prototype designed to support communities and authorities in the North Eastern Region of India.

It combines GIS-based risk visualization, hazard reporting, current warnings, and a centralized dashboard to support disaster preparedness, monitoring, and response.

## Key Features

- **Risk Map** — Interactive map for visualizing disaster-prone areas and risk information.
- **Report Hazard** — Allows users to report observed hazards such as landslides, floods, and road blockages.
- **Current Warnings** — Displays active disaster-related warnings.
- **Dashboard** — Provides an overview of available risk and hazard information.
- **Multi-language Support** — Supports Hindi, Assamese, Bengali, and Manipuri (Meitei) through translation links.

## Data Sources

- **Rainfall data** — India Meteorological Department (IMD)
- **Elevation & slope data** — SRTM (Shuttle Radar Topography Mission), via Bhuvan/OpenTopography
- **Landslide susceptibility** — National Remote Sensing Centre (NRSC), ISRO

> **Note:** Sample/reference values are used for this prototype demonstration. Live API integration with these data sources is planned as future scope.
